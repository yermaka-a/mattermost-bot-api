### Компоненты

1. **Бот на Go**: Основная программа, отвечающая за создание и управление опросами, взаимодействуя с пользователями через команды.

2. **Mattermost**: Mattermost используется в качестве платформы для общения и взаимодействия с ботом.

3. **Tarantool**: В качестве базы данных используется Tarantool для хранения данных о голосованиях и результатах.

4. **PostgreSQL**: Используется Mattermost для хранения данных о пользователях и настройках.

5. **Tarantool Admin**: Веб-интерфейс для просмотра и управления данными в Tarantool.

### Функциональные возможности бота

- **Создание опросов**: Команда `/create "вопрос" "вариант 1" "вариант 2"` позволяет создать новый опрос.
- **Голосование**: Команда `/vote ID_голосования вариант_ответа` позволяет пользователям голосовать в созданных опросах.
- **Просмотр результатов**: Команда `/results Id_голосования` выводит результаты текущего голосования.
- **Завершение опроса**: Команда `/finished Id_голосования` завершает опрос досрочно (доступно только создателю).
- **Удаление опроса**: Команда `/delete Id_голосования` позволяет удалить опрос (доступно только создателю).
- **Вступительное сообщение**: При первом открытии личных сообщений с ботом, он отправляет вступительное сообщение с описанием своего функционала.

### Конфигурация проекта 

- **Файл `.env`** содержит конфиденциальные данные, такие как пароли и токены, используемые в проекте.

### Запуск проекта

1. **Установка Docker и Docker Compose**: Убедиться, что они установлены на системе.

2. Скачать проект или клонировать его по ссылке: [mattermost-bot-api](https://github.com/yermaka-a/mattermost-bot-api) 

3. **Создание файла `.env`**: В корневой директории проекта прописать свои данные в файл .env, что представлен в примере:

   ```plaintext
   PASS=12345 # пример пароля для postgres
   BOT_TOKEN=z8yxbmc5tbbbtk9k4j4j3jghxw # пример токена доступа для бота в mattermost (Используйте свой)
   MATTERMOST_URL=http://app:8065 
   MATTERMOST_WS=ws://app:8065
   TARANTOOL_ADDR=tarantool:3301 
   TARANTOOL_PASS=passw0rd
   TARANTOOL_USER=storage
   ```

4. **Запуск Docker Compose**: Выполнить команду `docker-compose up --build` в терминале из директории, содержащей `docker-compose.yml` файл. Эта команда создаст и запустит все необходимые контейнеры.

5. **Проверка статуса контейнеров**: Убедиться, что все контейнеры работают без ошибок, используя команду `docker-compose ps`.

6. **Доступ к Mattermost**: Открыть веб-браузер и перейти по адресу [http://localhost:8065](http://localhost:8065), чтобы получить доступ к Mattermost.

7. **Доступ к Tarantool Admin**: Открыть веб-браузер и перейти по адресу [http://localhost:8080](http://localhost:8080) для управления Tarantool через веб-интерфейс.

8. **Взаимодействие с ботом**: В Mattermost создать direct message с ботом и ввести команды, чтобы начать взаимодействие, либо же провести те же действия в общем чате, где есть бот.
