# Mattermost-voting-bot
Проект представляет собой систему для создания опросов и голосований в Mattermost, написанную на языке Go. Он включает в себя следующие компоненты:

### Компоненты

1. **Бот на Go**: Основная программа, отвечающая за создание и управление опросами, взаимодействуя с пользователями через команды.

2. **Mattermost**: Mattermost используется в качестве платформы для общения и взаимодействия с ботом.

3. **Tarantool**: В качестве базы данных используется Tarantool для хранения данных о голосованиях и результатах.

4. **PostgreSQL**: Используется Mattermost для хранения данных о пользователях и настройках.

5. **Tarantool Admin**: Веб-интерфейс для просмотра и управления данными в Tarantool.

### Функциональные возможности бота
Взаимодействие происходит по протоколу WebSocket — протокол связи поверх TCP-соединения, предназначенный для обмена сообщениями между браузером и веб-сервером.<br/>

- **Создание опросов**: Команда `@create "вопрос" "вариант 1" "вариант 2"` позволяет создать новый опрос.

### Запуск проекта

1. **Установка Docker и Docker Compose**: Убедиться, что они установлены на системе.

2. Скачать проект или клонировать его по ссылке: [mattermost-bot-api](https://github.com/yermaka-a/mattermost-bot-api) 

3. **Работа с docker-compose-apps**: Выполнить команду  `docker-compose -f ./docker/docker-compose-apps.yaml up --build -d` в терминале из директории, содержащей директорию `docker`. Эта команда создаст и запустит контейнеры:
   1. `mattermost`
   2. `postgres`
   3. `tarantool`
   4. `tarantool-admin`

4. **Доступ к Mattermost**: Открыть веб-браузер и перейти по адресу [http://localhost:8065](http://localhost:8065), чтобы получить доступ к Mattermost.

5. **Создать бота в mattermost** - перейти в главном меню в `System Console` в поиске набрать `bots`, затем проставить разрешения на создание ботов.

6.  **Получить access token для бота и добавить его в `.env`** - перейти в главном меню в `integrations` создать бота, получить `access token`  добавить его в `.env` файл.

7. **Файл по пути `./docker/.env`**: прописать свой `access token` **(см. в п. 6)** в файл .env, как представлено в примере:

   ```plaintext
   PASS=12345 # пример пароля для postgres
   BOT_TOKEN=z8yxbmc5tbbbtk9k4j4j3jghxw # пример токена доступа для бота в mattermost (Используйте свой)
   MATTERMOST_URL=http://app:8065 
   MATTERMOST_WS=ws://app:8065 
   TARANTOOL_ADDR=tarantool:3301 
   TARANTOOL_PASS=passw0rd
   TARANTOOL_USER=storage
   ```

8. **Запустить бота** -  Выполнить команду  `docker-compose -f ./docker/docker-compose-bot.yaml up --build -d` в терминале из директории, содержащей директорию `docker`. Эта команда создаст и запустит бота.

9. **Доступ к Tarantool Admin**: Открыть веб-браузер и перейти по адресу [http://localhost:8080](http://localhost:8080) для управления Tarantool через веб-интерфейс.

10. **Взаимодействие с ботом**: В Mattermost создать `direct message` с ботом и ввести команды, чтобы начать взаимодействие, либо же провести те же действия в общем чате, где есть бот.

11. **Команда `@bot_help`** - возвращает сообщение с функционалом бота.
